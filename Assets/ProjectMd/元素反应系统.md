# 元素反应系统

## 概述

元素反应系统负责处理游戏中元素附着、元素衰减、元素反应触发以及反应衍生的持续状态效果。系统通过 `HurtSystem` 的伤害流水线作为入口，在造成伤害时自动检测目标身上的元素状态并触发相应反应。

---

## 架构总览

```
HurtComponentSystem (伤害处理)
    │
    ├─ ProcessElementReaction()
    │       │
    │       ├─ ElementBuffSystem.Reaction()     ← 路由到对应元素的反应表
    │       │       └─ ElementReaction.Reaction()  ← 遍历子反应列表，返回第一个命中
    │       │               └─ Reaction.Process()   ← 具体反应逻辑
    │       │
    │       ├─ [反应成功] → 修改伤害倍率/附伤 → 挂载 StatusEffect
    │       └─ [无反应]   → controller.AddElement() → 附着元素
    │
    └─ LoseHp() → 扣血
```

### 核心类职责

| 类 | 职责 |
|---|---|
| `ElementEnum` | 7 种元素枚举 (Fire/Water/Grass/Elect/Wind/Frost/Roach) |
| `ElementData` | 元素附着数据结构：档位、容量、附着时间、衰减公式 |
| `ElementBuffController` | MonoBehaviour，挂载于实体上，管理元素数组 + 状态效果字典 |
| `ElementDecayEvent` | 时间事件，元素量归零时标记 `Enable=false` |
| `ElementBuffSystem` | 反应系统入口，按攻击元素类型分发到对应 `ElementReaction` |
| `ElementReaction` | 单个元素的完整反应表（List\<Reaction\>），按优先级遍历 |
| `Reaction` | 反应基类，定义 `Process()` 接口 |
| `ReactionResult` | 反应结果：`DamageMultiplier` / `BonusDamage` / `TriggeredEffect` |
| `IStatusEffect` | 持续性效果接口 (Burn/Electrify/Freeze/Sharpen) |

## 元素附着机制

### ElementData 结构

```
Level:      元素档位 (1/2/4)，决定衰减速率
Capacity:   元素容量上限
AttachTime: 元素附着/刷新时刻
Enable:     是否生效
```

### 衰减速率

| Level | 衰减速率 (单位/秒) |
|-------|-------------------|
| 1     | 1000              |
| 2     | 1600              |
| 4     | 2000              |

当前剩余元素量计算：

```
GetVal(now) = max(0, Capacity - DecayRate × (now - AttachTime))
```

### 附着规则 (ElementBuffController.AddElement)

1. **首次附着**：`Capacity = ElementMeasure × 10000 × 0.8`，`Level = ElementMeasure`，`AttachTime = now`
2. **重复附着**（同元素）：
   - 新元素量 > 旧 Capacity → 强元素覆盖，刷新 AttachTime
   - 新元素量 ≤ 旧 Capacity → 补充元素量（不超过 Capacity），反推 AttachTime

### 消耗规则 (ElementBuffController.ConsumeElement)

```
消耗量 = val × 10000
当前量 ≤ 消耗量 → Enable = false（元素消除）
当前量 > 消耗量 → 反推新的 AttachTime
```

## 反应系统

### 路由机制

`ElementBuffSystem` 持有一个 `ElementReaction[8]` 数组，以攻击元素类型为索引：

```csharp
_reactions[1] = FireReaction;   // 火
_reactions[2] = WaterReaction;  // 水
_reactions[3] = GrassReaction;  // 草
_reactions[4] = ElectReaction;  // 雷
_reactions[6] = FrostReaction;  // 冰
```

### 反应优先级

每个 `ElementReaction` 内按 **List 添加顺序** 判定，命中第一个满足条件的即返回。不会同时触发多个反应。

## 元素量消耗规则详解

消耗规则标记 `(攻:受) = (攻击方消耗倍率 : 受击方消耗倍率)`：

```
攻击方剩余 = max(0, attackGauge - 受击方元素量 × 受击方倍率)
受击方消耗 = attackGauge × 攻击方倍率
```

### 增幅反应 (倍率不对称)

| 反应 | 攻击方倍率 | 受击方倍率 | 俗称 |
|-----|-----------|-----------|------|
| 火打水蒸发 | 0.5× | 2× | 弱火强水 |
| 水打火蒸发 | 2× | 0.5× | 强水弱火 |
| 火打冰融化 | 2× | 0.5× | 强火弱冰 |
| 冰打火融化 | 0.5× | 2× | 弱冰强火 |

**设计意图**：正向反应（水打火、火打冰）消耗更多攻击元素但获得更高倍率 (2.0×)；逆向反应（火打水、冰打火）消耗较少攻击元素但倍率较低 (1.5×)。

### 剧变反应 (倍率对称)

超载、超导：攻击方和受击方均为 1:1 消耗，附带固定范围伤害。

### 特殊反应

- **燃烧**：直接清除目标元素（`Enable = false`），无消耗计算
- **感电**：不消耗目标元素，反而向目标补充攻击方的元素附着（水雷共存）
- **激化**：1:1 消耗，挂载 10 秒 SharpenEffect；已激化目标再受雷/草攻击触发超激化/蔓激化（1.25× 倍率）

## 持续状态效果 (StatusEffect)

全部实现 `IStatusEffect` + `ITimeEvent`，通过 `TimeSystem` 调度定时逻辑。

### BurnEffect (燃烧)

| 属性 | 值 |
|------|-----|
| 持续时间 | 2.0 秒 |
| 触发间隔 | 0.25 秒 |
| 每次伤害 | 5 点火元素伤害 |
| 结束条件 | 持续时间到期 或 OnRemove 被调用 |

### ElectrifyEffect (感电)

| 属性 | 值 |
|------|-----|
| 触发间隔 | 0.5 秒 |
| 每次消耗 | 0.4 单位水 + 0.4 单位雷 |
| 结束条件 | 水或雷任一元素耗尽 或 OnRemove 被调用 |

### FreezeEffect (冻结)

| 属性 | 值 |
|------|-----|
| 持续时间 | 3.0 秒 |
| 结束条件 | 持续时间到期 或 OnRemove 被调用 |

### SharpenEffect (激化)

| 属性 | 值 |
|------|-----|
| 持续时间 | 10.0 秒 |
| 结束条件 | 持续时间到期 或 OnRemove 被调用 |
| 交互 | 存在期间，后续雷/草攻击触发超激化/蔓激化 (1.25×) |

## 伤害流水线

```
HurtComponent 入队
    │
    ├─ SkipReaction == true → 跳过反应，直接扣血
    │
    └─ SkipReaction == false:
        │
        ├─ 获取目标 ElementBuffController
        ├─ 调用 ElementBuffSystem.Reaction()
        │       │
        │       ├─ [命中反应] → 修改 HurtComponent.Harm
        │       │     Harm = Harm × DamageMultiplier + BonusDamage
        │       │     挂载 TriggeredEffect → controller.AddEffect()
        │       │
        │       └─ [未命中, ElementMeasure > 0] → controller.AddElement()
        │
        └─ LoseHp() → PlayerManager.HpModule.HurtHp()
                     → 飘字显示
                     → BodyController.LoseHp() (非玩家实体)
```

## 网络同步

元素附着和反应在以下上下文中执行：

- **客户端命中**（`SkipReaction = false`）：完整走反应流水线，产生视觉效果
- **服务端确认命中**（`SkipReaction = true`）：跳过反应计算，只扣血（服务端已完成反应判定并通过 `S2C_DamageConfirm` 下发最终伤害值）

元素附着/移除通过以下消息同步：

| 消息类型 | 方向 | 内容 |
|---------|------|------|
| `S2C_ElementAttach` | 服务端→客户端 | 目标ID、元素类型、档位、容量 |
| `S2C_ElementDetach` | 服务端→客户端 | 目标ID、元素类型 |
| `S2C_StatusEffect` | 服务端→客户端 | 目标ID、效果类型、新增/移除 |

客户端在 `Listener.cs` 中接收并调用 `ElementBuffController` 的对应方法。
