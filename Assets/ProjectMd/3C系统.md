# 3C 系统 (Character / Camera / Control)

## 概述

3C 系统负责玩家的**输入采集 → 状态决策 → 移动执行 → 相机跟随**的完整链路。输入层采用虚拟按键抽象，通过两层分发到达 PlayerManager 的模块；移动由 FSM 状态机设置速度参数，PlayerMoveModule 执行 CharacterController 物理；相机为第三人称轨道相机，支持 ADS 切换和墙壁碰撞检测。

## 一、输入系统 (Control)

### 两层架构

| 层 | 职责 | 关键类 |
|----|------|--------|
| 低层 | 物理按键 → 虚拟键 + 按键状态 → InputContext | `InputSystem`, `KeyState`, `KeyHandler` |
| 高层 | InputContext → PlayerManager 模块方法调用 | `PlayerInputController`, `InputActionHandler` |

### 低层：虚拟按键抽象

**KeyState** — 封装 Unity `KeyCode`，每帧采样 `GetKeyDown/GetKey/GetKeyUp`，输出 `Down/Press/Up` 和 `LongPress(0.2s)/DoubleClick(0.3s)`。

**KeyHandler** — 读取 `List<KeyState>`，将按键状态写入 `InputContext`：

| Handler | 写入字段 | 逻辑 |
|---------|---------|------|
| `MoveHandler` | `Context.Move` | W/A/S/D 组合成 Vector2 |
| `JumpHandler` | `Context.Jump` | 空格键 |
| `RunHandler` | `Context.Sprint` | Shift 按下 |
| `CrouchHandler` | `Context.Crouch` | Ctrl 按下 |
| `AttackHandler` | `Context.PrimaryAction` | 鼠标左键 |
| `ShootHandler` | `Context.SecondaryAction` | 鼠标右键（长按判定） |
| `ReloadHandler` | `Context.Reload` | R 键 |
| `ThrowGrenadeHandler` | `Context.Ability1` | G 键 |
| `ChangeWeaponHandler` | `Context.GetPrimaryWeapon/GetSecondaryWeapon` | 1/2 键 |
| `MouseScrollHandler` | `Context.MouseScroll` | 滚轮（0.3s 节流，目前未使用） |

**InputContext** — 输入共享数据结构：
```csharp
public class InputContext {
    public Vector2 Move;                    // WASD 移动向量
    public ButtonState PrimaryAction;       // 左键（攻击）
    public ButtonState SecondaryAction;     // 右键（瞄准/射击）
    public ButtonState Jump;                // 空格
    public ButtonState Sprint;              // Shift
    public ButtonState Crouch;              // Ctrl
    public ButtonState Reload;              // R
    public ButtonState Ability1;            // G（手雷）
    public ButtonState GetPrimaryWeapon;    // 1
    public ButtonState GetSecondaryWeapon;  // 2
    public float MouseScroll;               // 滚轮
}
```

**按键配置** — 通过 `KeyModel` 从 ScriptableObject 加载键位绑定，支持用户自定义并保存为 JSON。

### 高层：PlayerInputController

在 `LocalPlayerLogic.Init()` 中创建，`OnUpdate()` 中每帧调用 `Process(InputContext)`：

```
PlayerInputController
├── MoveActionHandler        → MoveModule.InputMove(context.Move)
├── JumpActionHandler        → MoveModule.InputJump() + buttons |= BUTTON_JUMP
├── CrouchActionHandler      → MoveModule.Crouch() + buttons |= BUTTON_CROUCH
├── SprintActionHandler      → MoveModule.RequestSprint() + buttons |= BUTTON_SPRINT
├── PrimaryActionHandler     → MoveModule.Sprint()（攻击键也触发冲刺检查）
├── SecondaryActionHandler   → CombatModule.Down/Press/UpSecondaryAction()
├── Ability1ActionHandler    → CombatModule.DownAbility1()
├── GetPrimaryWeaponHandler  → CombatModule.GetPrimaryWeapon()
├── GetSecondaryWeaponHandler→ CombatModule.GetSecondaryWeapon()
├── ReloadActionHandler      → 空实现（换弹逻辑在 LocalPlayerLogic.Update 中）
└── MouseScrollActionHandler → 空实现
```

## 二、角色系统 (Character)

### FSM 状态层级

角色下半身 FSM 决定**移动速度**和**核心行为**，上半身 FSM 决定**武器操作姿态**。

#### LowerBodyLayer 完整状态树

```
LowerBodyLayer
├── GroundLayer (条件: isGround)
│   ├── Idle          速度=0
│   │   └→ Combat     (条件: Move flag)
│   └── CombatLayer
│       ├── StandLayer (条件: !Crouch)
│       │   ├── Walk   速度=1.6
│       │   │   └→ Sprint  (条件: Sprint flag)
│       │   └── Sprint 速度=4.0
│       │       └→ Walk    (条件: !Sprint)
│       └── CrouchLayer (条件: Crouch)
│           ├── Walk   速度=1.6
│           │   └→ Sprint  (条件: Sprint flag)
│           └── Sprint 速度=3.5
│               └→ Walk    (条件: !Sprint)
├── AirLayer (条件: !isGround && alive)
│   ├── Jump
│   │   └→ Fall      (条件: !isJump)
│   └── Fall
│       └→ Jump      (条件: isJump)
└── GlobalInterruptLayer (条件: isDead)
    └── Dead
```

**速度配置（硬编码在各 State 中）：**

| 状态 | 速度 |
|------|------|
| Idle | 0 |
| Stand Walk | 1.6 |
| Stand Sprint | 4.0 |
| Crouch Walk | 1.6 |
| Crouch Sprint | 3.5 |

**IK 控制：** 冲刺和 Idle 状态会通过 `GetAimIkTarget()/GetHandIkTarget()` 调整 IK 权重。冲刺/换弹/拉栓/投掷时 IK 权重为 0。

#### UpperBodyLayer 状态

```
UpperBodyLayer
├── Aim      条件: WeaponFlags.Shoot（右键瞄准）
│   └→ Reload/Throw/Empty/Bolt
├── Reload   条件: WeaponFlags.Reload
├── Throw    条件: WeaponFlags.Throw
├── Bolt     条件: WeaponFlags.Bolt（拉栓）
└── Empty    条件: 以上都不满足（默认状态）
```

**PlayerAimState** — 上身朝向控制：
- `OnUpdateState()`: 本地玩家旋转朝向相机 Yaw 方向，`Slerp(t=20*deltaTime)`
- `OnExitState()`: 瞬间对齐到相机朝向

#### GlobalInterruptLayer — 死亡

```
Enter: DisableModule() + CreateDeathSnapshot() + DisableVisual()
Update: 本地玩家按 O 发送复活请求
Exit: EnableModule() + EnableVisual()
```

### 移动执行 (PlayerMoveModule)

#### 物理参数（硬编码）

| 参数 | 值 | 说明 |
|------|-----|------|
| 重力加速度 | -8 m/s² | `_gravity` |
| 终端速度 | -10 m/s | `_terminalVelocity` |
| 跳跃初速度 | 4 m/s | `_verticalVelocity` on jump |
| 地面粘滞速度 | -2 m/s | 贴地时保持的向下速度 |
| 固定时间步 | 0.02s (50Hz) | `OnFixedUpdate` 中写死 |

#### OnFixedUpdate 核心逻辑

```csharp
// 1. 计算朝向（基于相机 Yaw）
Vector3 forward = Quaternion.Euler(0, CameraController.Yaw, 0) * Vector3.forward;
Vector3 right   = Quaternion.Euler(0, CameraController.Yaw, 0) * Vector3.right;

// 2. 计算水平移动
Vector3 move = forward * _move.y + right * _move.x;
if (_isGround)
    horizontalMove = move.normalized * (_moveSpeed * 0.02f);
else
    horizontalMove = _airVelocity * 0.02f;  // 空中锁定速度

// 3. 玩家旋转
Quaternion targetRot = Quaternion.LookRotation(forward);
transform.rotation = Quaternion.Slerp(current, targetRot, 0.02f * 10f);

// 4. CharacterController 移动
controller.Move(horizontalMove + Vector3.up * _verticalVelocity * 0.02f);

// 5. 地面检测 + 重力
CheckGrounded();   // SphereCast 从 pos+0.2m 向下 0.2m, 半径=controller.radius*0.9
ApplyGravity();    // 地面: -2.0 粘滞; 空中: 累加-8*0.02, 限制到-10
```

#### 地面检测

```csharp
SphereCast(origin = position + up*0.2f, radius = controller.radius*0.9f,
           direction = down, maxDistance = 0.2f)
// 命中且法线角度 ≤ 45° → 判定为地面
```

#### 空中移动

离开地面时快照水平速度方向：`_airVelocity = move.normalized * _moveSpeed`，空中移动使用此锁定的速度，不允许空中变向。

#### 跳跃与蹲下交互

```csharp
InputJump():
  if (!isGround) return;           // 空中不能跳
  if (isCrouch) { isCrouch=false; return; }  // 蹲下时按跳 → 站起
  isJump = true;
  verticalVelocity = 4f;
```

#### 状态查询 (PlayerMoveQuery)

每帧 `GetQuery()` 将模块内部 bool 字段组合为位掩码：

| 位 | 含义 | 来源 |
|----|------|------|
| Ground | 在地面 | `_isGround` |
| Jump | 跳跃中 | `_isJump` |
| Sprint | 冲刺中 | `_isSprint` |
| Crouch | 蹲下 | `_isCrouch` |
| Sliding | 滑铲中 | `_isSliding` |
| Forward/Back/Left/Right/FL/FR/BL/BR | 8方向 | `_move` 向量解析 |
| Move | 有移动输入 | 任一方向位被设置 |

## 三、相机系统 (Camera)

### CameraController

第三人称轨道相机，挂载在相机 GameObject 上。

#### 可调参数 (Inspector)

| 参数 | 默认值 | 说明 |
|------|--------|------|
| sensitivity | 2 | 鼠标灵敏度 |
| distance | 2m | 第三人称相机距离 |
| aimDistance | 1m | 肩射/瞄准时相机距离 |
| height | 1.5m | 相机焦点高度（蹲下→1.2m） |
| minPitch / maxPitch | -30° / 60° | 俯仰限制 |
| shoulderOffset | 0.2m | 右肩偏移（正=右肩视角） |
| rayLength | - | 屏幕中心射线长度 |
| wallOffset | 0.1m | 墙壁碰撞时相机回退距离 |

#### FixedUpdate — 高度调整

```
蹲下时: height → 1.2m (MoveTowards)
站立时: height → 1.5m
```

#### LateUpdate — 轨道旋转 + ADS 切换

```
1. 鼠标输入 → yaw(Repeat) + pitch(Clamp)
2. 旋转: Quaternion.Euler(pitch, yaw, 0)

3. ADS 判定:
   if (Shoot && !Shoulder && !Throw && !Bolt):
     → 相机切到 scopeCamera 位置
     → 隐藏头部渲染层
   else:
     → 第三人称距离插值 (Shoulder→1m, 其他→2m)
     → camPos = targetPos - forward*distance + right*shoulderOffset
     → CheckWall() 墙壁碰撞检测
     → 恢复头部渲染
```

**ADS 判定条件：** 必须同时满足 4 个条件（`WeaponFlags.Shoot && !Shoulder && !Throw && !Bolt`），即完全开镜状态。

#### UpdateForward (每帧 LateUpdate 中调用)

屏幕中心射线检测，计算 `rayEnd`（瞄准点）和 `hitEnd`（命中点）：

- 射线命中 → 检查命中点到枪托距离。过近（`< endDistance²`）→ 指向远处（`rayLength`），防止贴墙时瞄准错乱
- 未命中 → 指向射线最大距离

`rayEnd` 被 `PlayerIkModule` 读取用于 AimIK 目标点设置。

#### CheckWall — 相机碰撞

从玩家焦点位置向理想相机位发射 Raycast：
- 无遮挡 → 直接使用理想位置
- 有遮挡 → 相机放在碰撞点前方 `wallOffset` 处

## 四、完整执行流程

```
每帧顺序:

1. Update (render rate)
   ├── GameEnter.Update() → InputSystem.SetKeyCode()
   │   → KeyState 采样 → KeyHandler 写入 → InputContext
   ├── LocalPlayerLogic.OnUpdate()
   │   ├── PlayerInputController.Process(InputContext)
   │   │   → 各 ActionHandler 调用 Module 方法
   │   ├── state.aimPosition = CameraController.rayEnd
   │   ├── AnimController.Update()
   │   └── IkModule.OnUpdate()
   └── PlayerController.Update()
       └── PlayerFsm.Update()
           ├── LowerBodyLayer.Update()
           │   → CheckConditions → 状态转移 → OnEnter/OnUpdate/OnExit
           │   → 设置 MoveModule.SetSpeed()
           └── UpperBodyLayer.Update()
               → AimState: 旋转角色朝向相机

2. ClientTick (50Hz FixedUpdate)
   ├── 写 Position/Rotation 到 StateData
   ├── SampleInput() → 收集输入采样 → _pendingSamples
   ├── Reload() 换弹轮盘逻辑
   ├── CombatModule.OnFixedUpdate()  → 武器 Tick
   └── MoveModule.OnFixedUpdate()
       → 计算朝向 → 水平移动 → 旋转 → CharacterController.Move()
       → CheckGrounded → ApplyGravity

3. LateUpdate
   ├── CameraController.UpdateForward()
   │   → Shooting() 射线检测 → rayEnd/hitEnd
   └── CameraController.LateUpdate()
       → 鼠标输入 → yaw/pitch → 轨道计算 → CheckWall → 设置位置
```

## 五、关键设计决策

### 1. 输入双层抽象

物理按键 → 虚拟键 → InputContext → ActionHandler → Module。每一层只关心自己的抽象级别，换键位只需修改 KeyModel 的键位绑定配置。

### 2. 相机 Yaw 作为移动基准

`PlayerMoveModule` 和 `PlayerAimState` 不直接读鼠标输入，而是读 `CameraController.Yaw`。意味着：
- 移动方向始终跟随相机朝向
- 瞄准时旋转角色也跟随相机朝向
- 相机 Yaw 成为角色朝向的唯一数据源

### 3. FSM 与 Module 职责分离

- **FSM** 负责"应该是什么速度/IK 权重"（`SetSpeed`, `SetAimIk`, `SetHandIk`）
- **MoveModule** 负责"在当前速度下怎么移动"（物理计算、地面检测、重力）

但仍有耦合：`MoveModule.Sprint()` 内部有大量条件判断（是否面向前方、是否在射击等），这些判断逻辑与 FSM 的 SprintState 条件有重复。

### 4. 空中速度锁定

离开地面瞬间快照水平速度方向，空中不能改变移动方向。这是常见的 FPS/TPS 跳跃设计，避免空中飘移感。

### 5. 相机墙壁碰撞

使用 Raycast 检测遮挡，保证相机不会穿墙。碰撞后相机回退到遮挡物表面，而非直接切到第一人称。

### 6. 硬编码参数

移动速度、重力、跳跃初速度、相机参数全部以字面量或 Inspector 字段方式硬编码，没有 ScriptableObject 配置层。`ServerMoveModule` 中复制了相同的物理参数，存在不同步风险。
