# GenshinObject 项目介绍

## 项目概述

GenshinObject 是一个基于 Unity 引擎开发的第三人称射击游戏原型项目，融合了射击战斗与元素反应机制。项目采用 **QFramework** 架构进行模块化开发，拥有约 500 个 C# 脚本，涵盖角色控制、武器系统、AI 敌人、动画系统、网络同步等多个系统。

## 技术栈

- **引擎**: Unity（使用 URP 渲染管线）
- **架构框架**: QFramework
- **网络传输**: FlatBuffers
- **资源管理**: 自定义 AssetBundle 系统
- **IK 系统**: Final IK
- **UI 库**: TextMesh Pro、DoTween

## 核心系统

### 1. 角色系统

- **层次状态机 (HFSM)**: 角色的状态管理从传统有限状态机重构为层次状态机，分为上层（上半身）和下层（下半身）状态，支持站立/蹲伏/空中等姿态，以及行走/冲刺/滑铲等移动方式
- **模块化管理**: PlayerManager 采用模块拆分设计，包括：
  - `CombatModule` — 战斗模块，处理武器信息与武器逻辑
  - `ViewModule` — 视图模块，处理武器 UI 展示
  - `IkModule` — IK 模块，处理角色和手部 IK
  - `MoveModule` — 移动模块，处理角色位移和跳跃
  - `BagModule` — 背包模块，处理背包数据
  - `HpModule` — 血量模块

### 2. 武器系统

- **组合式设计**: 武器由 WeaponFeature 和 WeaponComponent 组成
  - `WeaponFeature` — 通过 FeatureData 在 WeaponFeatureFactory 创建，通过组合实现武器特性（射击、换弹、拉栓、姿态切换）
  - `WeaponComponent` — 通过 ComponentData 在 WeaponComponentFactory 创建，纯数据存储（弹匣、伤害、音效、Transform）
- **武器状态机**: 每种武器拥有独立的 FSM（如 FN_IWS、SPR2），管理 Idle/Shoot/Reload/Bolt 等状态
- **支持的武器类型**: 步枪 (MK14、HK416)、狙击枪 (FN_IWS)、投掷物（手雷）

### 3. 动画系统

- **自定义动画树**: 实现了可编辑器配置的动画树 (AnimGraph)，支持 Mix 节点、Layer 混合节点、Leaf 节点和 Slot 节点
- **动画复用**: 优化了动画树节点，支持节点的复用
- **动画曲线**: 通过读取特定动画曲线实现换弹动画等复杂逻辑
- **上下半身分离**: 上半身和下半身动画独立控制，通过权重混合

### 4. 元素反应系统

参考原神元素机制，实现了元素反应与 Buff 系统：

| 元素 | 反应效果 |
|------|----------|
| 火 + 草 | **燃烧**: 持续 2s，每 0.25s 造成 5 点伤害 |
| 雷 + 草 | **激化**: 持续 10s，雷/草元素伤害提升 1.25 倍 |
| 水 + 火 | 蒸发 |
| 冰 + 火 | 融化 |
| 雷 + 水 | 感电 |

Buff 系统支持独立的 Buff 管理和状态效果。

### 5. AI 系统

- **EQS 环境查询系统**: 用于敌人 AI 的决策制定
  - `EQSContext` — 储存环境信息
  - `EQSTest` — 处理待选点权重评分（NavMesh 可达性、玩家可见性、距离）
  - `EQSGenerator` — 初始化待选点（矩形选择用于寻找掩体、圆周选择用于围绕攻击）
- **AI 感知**: 视觉感知 (AISightPerception)、听觉感知 (AIHearingPerception)、伤害感知 (AIDamagePerception)
- **敌人状态**: 巡逻、战斗、寻找掩体、撤退、受伤、死亡

### 6. 网络系统

- 使用 **FlatBuffers** 进行数据传输，替代了早期的 JSON 格式
- 支持**本地回环**模式，单机和服务器可共用一套代码逻辑
- 同步内容包括：角色状态、射击数据、受击数据、武器状态
- 包含数据包大小监听器，用于网络性能监控

### 7. 资源管理

- 自定义 **AssetBundle 框架**，支持编辑器模式和运行时模式
- 编辑器下自动分析 AssetBundle 的依赖文件并递归显示
- 资源加载支持同步和异步方式

## 项目目录结构

```
Assets/
├── Anim/              # 动画资源
├── Character/         # 角色模型与贴图
├── Fbx/               # FBX 模型文件
├── Materials/         # 材质
├── Plugins/           # 第三方插件
├── Resources/         # 动态加载资源（武器、子弹、预制体）
├── Scenes/            # 场景文件
├── Scripts/           # 核心代码
│   ├── AI/            # AI 感知、EQS、可视化
│   ├── AssetBundleFramework/  # AssetBundle 资源管理
│   ├── Connect/       # 网络同步与 FlatBuffers
│   ├── Editor/        # 编辑器工具（动画图编辑等）
│   ├── Enemy/         # 敌人动画与行为
│   ├── Factory/       # 工厂模式（武器、手雷、狙击）
│   ├── Firearms/      # 枪械组件（子弹、弹匣、枪口）
│   ├── GameFSM/       # 状态机（武器、关卡、玩家、敌人）
│   ├── Player/        # 玩家动画树、IK、模块
│   ├── mController/   # 输入控制器
│   ├── mEnum/         # 枚举定义
│   ├── mEvent/        # 事件系统
│   ├── mInterface/    # 接口定义
│   ├── mModel/        # 数据模型
│   ├── mSystem/       # 系统逻辑（Buff、子弹、EQS、伤害等）
│   ├── mView/         # 视图层
│   └── mWeapon/       # 武器数据、特性、组件
├── SpecialEffects/    # 特效资源
└── TextMesh Pro/      # 文字渲染
```

## 开发环境

- Unity 版本: 支持 URP (Universal Render Pipeline)
- 目标平台: Windows
- 语言: C#
